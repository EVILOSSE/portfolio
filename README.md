## Selected work

- **Hawa Shop:** a French-language electronics storefront prototype. The supplied recording demonstrates catalogue and product pages; live orders, payments and a production database are not demonstrated.
- **[AI Video Workspace](VIDEO-WORKSPACE.md):** an original local browser UI and Node.js proxy for a video-generation API. Four existing tests pass against a local test relay. This sample includes source and tests, without credentials or generation history.
- **[Website Check](WEBSITE-CHECK.md):** an original dependency-free Python utility for inspecting saved HTML. Seven existing tests pass. It is a static source checker, not an accessibility certification.

The project briefs and visual decisions were directed by Zakaria. Implementation used AI assistance. The source samples and limits are provided so a reviewer can assess the work directly.

## Source

- [Portfolio source archive](portfolio-source.zip): React, TypeScript, Vite and Motion. Extract, run `npm ci`, then `npm run dev`. `npm run build -- --base=/portfolio/` builds for the GitHub Pages subdirectory.
- [Video workspace source archive](video-workspace-source.zip): extract, run `npm test`, then configure your own API key locally if you want to use the provider integration.
- [Website Check source archive](website-check-source.zip): extract and run `python -m unittest -v test_website_check.py`.

Source and media attribution are included in the archives. The portfolio uses ESA/Hubble space footage, Manrope, MynaUI icons, ReactDrops Shape Physics, and Jakub Antalik's Libraries.dev Waves (MIT).
